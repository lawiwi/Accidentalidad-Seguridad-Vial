7. Calidad inicial de los datos

Diagnóstico preliminar de integridad, consistencia, duplicidad, valores faltantes y cobertura de las fuentes.

Objetivo del diagnóstico

En esta etapa se realiza una evaluación inicial del estado de los datos antes de aplicar procesos de limpieza, transformación o modelado.

Importante: No se eliminaron registros ni se modificaron los valores originales. El propósito de este diagnóstico es identificar problemas potenciales que deberán ser considerados durante las siguientes etapas del proyecto.

Los valores faltantes representan una proporción muy pequeña respecto a los 406.540 registros del dataset. Sin embargo, deberán ser considerados cuando se realicen análisis que utilicen específicamente estas variables.

Registros duplicados

Siniestros Viales

0 duplicados completos. Tampoco se encontraron identificadores hechos_id duplicados.

Vehículos involucrados

147.575 registros duplicados completos.

Este resultado representa aproximadamente el 36,3 % del dataset de vehículos.

Sin embargo, en esta etapa no se eliminarán automáticamente estos registros, debido a que un mismo conjunto de características puede corresponder a registros legítimos provenientes de diferentes reportes o eventos.

En una etapa posterior será necesario determinar si los duplicados corresponden a registros realmente repetidos o a observaciones válidas.

Inconsistencias y valores sospechosos

Edad del vehículo

Valor máximo detectado: 1826 años.

La variable edad_vehiculo presenta valores que no parecen compatibles con la antigüedad real de un vehículo. Esto puede deberse a errores de registro, problemas de formato o inconsistencias en la fuente original.

Este comportamiento deberá ser investigado antes de utilizar esta variable en modelos estadísticos o algoritmos de minería de datos.

Modelo del vehículo

Valor máximo detectado: 2027.

El dataset tiene registros hasta febrero de 2026, pero se identificaron vehículos con modelo 2027. Estos registros deberán revisarse para determinar si corresponden a vehículos registrados como modelos futuros o si representan errores en los datos.

Consistencia geográfica

Se identificaron diferencias en la cobertura territorial entre las dos fuentes. Aunque existen departamentos y municipios comunes, no todos aparecen en ambos datasets.

Esta diferencia debe considerarse al realizar comparaciones territoriales para evitar interpretar las diferencias de cobertura como diferencias reales en accidentalidad.

Consistencia temporal

No existen años comunes entre las dos fuentes.

Por esta razón, no es metodológicamente adecuado realizar una unión registro a registro utilizando la fecha del accidente como llave.

Los datasets serán utilizados como fuentes complementarias, permitiendo estudiar diferentes dimensiones del fenómeno de accidentalidad vial.

🔗 Problemas de integración

El diagnóstico de integración permitió identificar:

  • 27 departamentos presentes en ambas fuentes.
  • 455 municipios comunes.
  • 0 fechas comunes.
  • 0 combinaciones comunes de fecha + departamento.
  • 0 combinaciones comunes de fecha + municipio.
  • 0 combinaciones comunes de fecha + departamento + municipio.
Decisión metodológica:

No se realizará un merge directo entre los datasets. Las fuentes serán utilizadas de manera complementaria para analizar diferentes características de la accidentalidad vial en Colombia.

Posibles sesgos y limitaciones de calidad

  • Diferencias en los periodos de cobertura entre las fuentes.
  • Diferencias en la cobertura territorial.
  • Posibles diferencias en los mecanismos de reporte.
  • Alta concentración de registros en determinados departamentos y municipios.
  • Presencia de valores faltantes en algunas variables del dataset de vehículos.
  • Presencia de registros duplicados que requieren investigación antes de ser eliminados.
  • Valores potencialmente inconsistentes en la edad y modelo de los vehículos.

Conclusión del diagnóstico

Los datasets presentan información suficiente para continuar con el proyecto de minería de datos y cumplen con los requisitos básicos de cantidad de registros, variables, cobertura geográfica y presencia de información temporal.

El dataset de siniestros presenta una estructura relativamente completa, sin valores faltantes ni duplicados completos. Por otra parte, el dataset de vehículos posee un volumen considerablemente mayor y permite incorporar características específicas de los vehículos involucrados.

Los problemas identificados serán documentados y tratados durante las siguientes etapas. En esta fase se conserva la información original para garantizar la trazabilidad de los datos.

Estado: Diagnóstico inicial completado. Los datos están listos para continuar con las siguientes etapas de preparación y análisis.
