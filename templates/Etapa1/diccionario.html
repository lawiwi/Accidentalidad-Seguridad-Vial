6. Diccionario de Datos

Descripción de las variables utilizadas en los datasets seleccionados para el proyecto de minería de datos.

Propósito del diccionario

El diccionario de datos permite identificar el significado, tipo, dominio, unidad de medida, procedencia y utilidad analítica de cada variable utilizada en el proyecto.

El proyecto utiliza dos fuentes principales de información: el dataset de Siniestros Viales de la Agencia Nacional de Seguridad Vial (ANSV) y el dataset de Vehículos involucrados en accidentes de tránsito disponible en Datos Abiertos Colombia.

Debido a que ambos conjuntos presentan diferentes periodos de cobertura y no poseen una llave común que permita realizar una integración registro a registro, serán tratados como fuentes complementarias.

Trazabilidad e integración

Los datasets fueron obtenidos de fuentes institucionales relacionadas con la seguridad vial en Colombia.

Durante el diagnóstico de integración se identificaron coincidencias geográficas entre departamentos y municipios, pero no existen años ni fechas comunes entre los dos conjuntos de datos disponibles.

Resultado:

Los datasets no se integrarán mediante un merge registro a registro. Se utilizarán como fuentes complementarias para ampliar el análisis del fenómeno de accidentalidad vial.

El dataset de siniestros permite estudiar principalmente características del hecho, ubicación, causas, víctimas y tipo de vía, mientras que el dataset de vehículos permite analizar características del parque automotor involucrado, como tipo, marca, modelo y edad del vehículo.
