📊 5. Dataset

Etapa 1 — Problema, fuentes y caracterización de datos

📁 Dataset principal

Para el desarrollo del proyecto de minería de datos se seleccionó como conjunto de datos principal el dataset Vehículos involucrados en un accidente de tránsito , publicado a través de Datos Abiertos Colombia. El conjunto contiene información relacionada con los vehículos involucrados en accidentes de tránsito registrados en Colombia, incluyendo características del vehículo, fecha y ubicación del accidente y gravedad del evento.

Este dataset fue seleccionado debido a que presenta una cobertura temporal más amplia que la fuente inicialmente analizada y permite estudiar la relación entre las características de los vehículos, la ubicación y la gravedad de los accidentes.

🔗 Integración con otras fuentes

Como fuente complementaria se dispone del dataset de Siniestros Viales ANSV , que contiene 19.015 registros correspondientes al periodo 2019-01-01 a 2019-08-14. Debido a que ambos conjuntos de datos no presentan coincidencias temporales suficientes para realizar una unión registro a registro, se decidió conservarlos como fuentes complementarias.

⚠️ No se realizará un merge directo entre ambos datasets utilizando fecha, departamento y municipio. La integración se realizará posteriormente mediante análisis comparativos y agregaciones, preservando la trazabilidad de cada fuente.
