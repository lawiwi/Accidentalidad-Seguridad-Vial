4. Fuentes de datos

Fuentes utilizadas para contextualizar y analizar la accidentalidad vial.

Clasificación de las fuentes

Para el proyecto se consideran fuentes de información de diferentes niveles. Las fuentes secundarias constituyen la base principal del análisis cuantitativo, mientras que las fuentes primarias y terciarias permiten complementar el contexto y la interpretación del fenómeno.

🇨🇴 Siniestros viales ANSV ↗

SECUNDARIA 01/01/2019 – 14/08/2019 ↓ CSV

Datos de Siniestros Viales

Institución: Agencia Nacional de Seguridad Vial (ANSV)
Fuente: Servicio geográfico institucional / ArcGIS
Registros: 19.015
Variables: 16 variables originales
Cobertura: Colombia
Departamentos: 32
Municipios: 799
Formato obtenido: JSON mediante API REST y posteriormente CSV
Método de adquisición: Consulta automatizada mediante API
Archivo local: data/siniestros_viales.csv

Esta fuente permite analizar características temporales, geográficas y relacionadas con los siniestros, incluyendo ubicación, clasificación, hipótesis, víctimas y lugar del accidente.

🌎 Fuentes terciarias

TERCIARIA

Datos Abiertos Colombia

El portal Datos Abiertos Colombia funciona como plataforma de distribución y consulta de conjuntos de datos publicados por diferentes entidades públicas. Para este proyecto se utiliza como mecanismo de acceso y consulta de información pública relacionada con movilidad y accidentalidad.

Institución responsable: Gobierno de Colombia
Tipo: Portal de distribución de datos
Cobertura: Nacional

📝 Fuente primaria propuesta

PRIMARIA

Observación directa / levantamiento propio

Como fuente primaria complementaria se plantea la posibilidad de realizar observación directa de condiciones relacionadas con la movilidad y seguridad vial en un contexto regional.

Esta información no será utilizada para modificar los registros oficiales descargados. En caso de realizarse, funcionará como información contextual adicional y deberá documentarse mediante fecha, ubicación, metodología de observación y variables registradas.

🔗 Integración de las fuentes

Las dos fuentes secundarias principales no presentan coincidencia temporal suficiente para realizar una integración registro a registro. El dataset de siniestros corresponde a 2019, mientras que el dataset de vehículos contiene información desde 2022.

Por esta razón, las fuentes serán utilizadas como datasets complementarios. Se podrán realizar comparaciones y análisis independientes utilizando dimensiones comunes como departamento, municipio y características de los accidentes, sin afirmar que un registro de una fuente corresponde directamente a un registro de la otra.

⚠️ Limitaciones de las fuentes

  • Las fuentes tienen diferentes periodos de cobertura.
  • Los nombres de municipios y departamentos pueden presentar diferencias de formato.
  • Las fuentes poseen diferentes niveles de granularidad.
  • El dataset de vehículos presenta registros duplicados.
  • Existen algunos valores faltantes en marca y edad del vehículo.
  • La cobertura territorial no es idéntica entre ambas fuentes.
