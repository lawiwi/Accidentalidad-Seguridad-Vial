ETAPA 2 · CALIDAD DE DATOS

Requisitos de calidad

Definición de las condiciones que deben cumplir los datos para que puedan ser utilizados de manera confiable en el análisis de accidentalidad vial.

01

¿Qué se entiende por requisito de calidad?

Un requisito de calidad establece una condición que los datos deben cumplir para ser considerados adecuados para el propósito del análisis.

Para este proyecto, los requisitos se definen a partir de las características del dataset de vehículos involucrados en accidentes de tránsito y de las necesidades del análisis de accidentalidad vial.

Objetivo principal: garantizar que los registros utilizados en el análisis sean completos, válidos, consistentes, únicos y suficientemente actuales para producir resultados confiables.
02

Requisitos definidos para el dataset

Se establecen seis dimensiones principales de calidad. Cada una será evaluada posteriormente mediante indicadores cuantificables.

Completitud

Las variables relevantes deben contener información suficiente y los valores faltantes deben ser identificados y cuantificados.

Exactitud

Los valores registrados deben representar de manera adecuada la información correspondiente al vehículo y al accidente.

Consistencia

Las variables relacionadas deben mantener relaciones lógicas entre sí y no presentar contradicciones.

Unicidad

Los registros que representen exactamente la misma información no deben encontrarse duplicados.

Validez

Los datos deben respetar los formatos, rangos, categorías y dominios definidos para cada variable.

Oportunidad

Las fechas y períodos registrados deben permitir determinar cuándo ocurrió cada accidente y conocer las posibles limitaciones de actualización.

03

Requisitos específicos por variable

Además de evaluar la calidad general del dataset, cada variable debe cumplir condiciones relacionadas con su naturaleza y utilización dentro del análisis.

Variable Requisito Verificación
marca_vehiculo Debe contener una marca identificable o quedar explícitamente marcada como no registrada. Valores nulos, vacíos y categorías.
modelo_vehiculo Debe representar un año de modelo válido y razonablemente relacionado con la fecha del accidente. Rango, tipo de dato y consistencia temporal.
tipo_vehiculo Debe pertenecer a una categoría reconocible de vehículo. Valores únicos y categorías.
edad_vehiculo Debe corresponder a una edad razonable del vehículo y no presentar valores imposibles. Valores nulos, mínimos, máximos y posibles valores atípicos.
fecha_accidente Debe utilizar un formato de fecha válido y permitir identificar el período del accidente. Conversión de fechas y valores no válidos.
gravedad_accidente Debe corresponder a una categoría de gravedad definida por la fuente. Categorías y valores fuera de dominio.
departamento_accidente Debe corresponder a una división territorial reconocible de Colombia. Valores únicos y homologación territorial.
municipio_accidente Debe corresponder a un municipio asociado al departamento registrado. Consistencia entre municipio y departamento.
autoridad_de_transito Debe mantener una denominación consistente para facilitar agrupaciones y análisis. Categorías, textos y valores inconsistentes.
04

Criterios de aceptación

Los requisitos anteriores se convierten en criterios verificables mediante el perfilamiento y las métricas de calidad.

1

Identificar y cuantificar todos los valores faltantes presentes en las variables.

2

Detectar registros completamente duplicados y determinar qué proporción representan del dataset.

3

Comprobar que las variables numéricas se encuentren dentro de rangos razonables.

4

Verificar que las variables categóricas utilicen valores reconocibles y consistentes.

5

Validar que las fechas puedan convertirse correctamente y que permitan establecer el período de cada accidente.

6

Detectar inconsistencias entre variables relacionadas, especialmente entre año del modelo, edad del vehículo y fecha del accidente.

7

Documentar las limitaciones de exactitud cuando no exista una fuente externa de referencia que permita comprobar directamente el valor registrado.

05

¿Cómo se comprobarán los requisitos?

La evaluación se realizará mediante un proceso de perfilamiento y análisis estadístico del dataset. Los resultados permitirán determinar qué requisitos se cumplen y cuáles requieren tratamiento.

Etapa Actividad Resultado esperado
Perfilamiento Revisar estructura, tipos, valores únicos, nulos y estadísticas descriptivas. Diagnóstico inicial del dataset.
Medición Calcular indicadores para cada dimensión de calidad. Porcentajes y cantidades verificables.
Diagnóstico Identificar problemas, variables afectadas y posibles causas. Inventario de problemas de calidad.
Tratamiento Aplicar reglas justificadas de limpieza, normalización y validación. Dataset preparado para análisis.
Comparación Comparar los indicadores antes y después del tratamiento. Evidencia del mejoramiento de la calidad.
06

Resultado esperado

Los requisitos definidos servirán como referencia para evaluar objetivamente la calidad del dataset durante las siguientes etapas. De esta manera, los problemas detectados podrán relacionarse con una dimensión específica y recibir un tratamiento sustentado en evidencia.

El propósito no es modificar los datos arbitrariamente, sino establecer reglas reproducibles que permitan mejorar su utilidad para el análisis de accidentalidad vial.
